## ⚠️ Repository Notes

- **AI dashboard:** `Algorithm Comparison Dashboard.py` imports from `Project.py`, but the available algorithm module is named `Algorithms.py`. Align the import and filename before launching the Streamlit app.
- **Power BI materials:** `PythonProject.pbix` is 2 bytes in the current `main` branch and appears incomplete. Replace it with the intended report before opening it in Power BI Desktop.
- **FCFS scheduler:** assumes every process arrives at time zero and runs in input order; arrival times are not part of the input.
